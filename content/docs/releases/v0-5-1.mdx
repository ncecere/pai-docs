## What's fixed

- **The page no longer zooms in when you tap a text field, and stays zoomed.** iOS Safari zooms into any field with text under 16px, and doesn't zoom back out, so after each tap the page had to be pinched back to size. On touch screens every text field (the message box, the conversation search, the fields in Settings and Admin, and those in dialogs) is now at least 16px. Desktop sizes are unchanged, and pinch-zoom is still allowed. The browser tests now check every page and dialog. See [Accessibility](/docs/use/accessibility#what-is-checked-automatically).
- **The greeting** ("What should Assistant work on, Priya?") no longer starts its second line with the comma on a phone.
