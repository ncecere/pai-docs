**On `main` since v0.1.0, not yet released.** These docs describe it, at commit `3ae3d9e`. Migrations 1 and 2.

## The app's own database

- Pi Agent Interface has its own PostgreSQL (`DATABASE_URL`), migrated on start: the people who have signed in, their role, settings, preferences and an audit log. Conversations stay on the platform. See [PostgreSQL and migrations](/docs/operate/database).
- `INITIAL_ADMIN_EMAIL` makes the first administrator; `pnpm admin:promote <email>` recovers from a lockout. There is always at least one active administrator. See [The first administrator](/docs/administer/first-administrator).
- A suspension, or **Sign out everywhere**, ends the person's sessions within seconds.

## Admin dashboard

- `/admin`, for administrators, in Open Chat Interface's layout: **Overview** (people, activity, recent changes), **People** (search, make administrator or member, suspend or restore), **Branding** (name, logo, default accent and appearance, shown on every page and the sign-in page) and the **Audit log**. See [Administer](/docs/administer).
- **Agents**: the default model (instead of `AGENT_MODEL`, which remains the fallback), how many agents each person may make (default 5), whether people choose the model, and the templates allowed. **Provided agents**: agents everyone gets, each person their own private copy; the built-in assistant is the first. See [Agents](/docs/administer/agents).
- **Features**: optional parts of the app an instance can do without, enforced by the server, hidden in the browser when off, and lockable off with `DISABLED_FEATURES`. See [Features](/docs/administer/features).
- **Usage** (an optional feature, on by default): requests, tokens and an estimated cost per person over 7, 30 or 90 days, with tokens per day, from the platform's usage report. See [Usage](/docs/administer/usage).

## Settings

- `/settings`, in Open Chat Interface's layout: **Account** (profile from sign-in, sign out, sign out everywhere), **Customization** (light, dark or system, accent, avatar style, Enter behaviour, code wrapping) and **Conversations** (archived and settled, restore or delete, one by one or together). Appearance is saved to the person's account, so it follows them between devices. See [Settings](/docs/use/settings).
- **My agents**: people make their own agents from the allowed templates, rename them, move them to another model, and delete them. The agent picker groups provided agents and your own. See [Agents](/docs/use/agents).
- **Personal usage** (an optional feature, off by default): Settings → Usage shows each person their own agents' requests, tokens and estimated cost, per agent and per day.

## The inbox

- **It follows the platform live.** One event stream per signed-in person, through a single shared connection to the platform's event stream, updates conversation lists as they change on any device, and the platform's own status drives **Working**, **Done** and **Failed**. Replies that finish while the app is closed show as **Done** when you come back.
- **It follows you between devices**: pinned, snoozed, settled, archived and read are saved to your account. Each conversation's latest change wins, removals included.
- Three-line rows (agent, title, time), the status in the corner with an icon (**Working** with a timer, **Done**, **Failed**, **Woke**), a pin on pinned rows, compact times (now, 5m, 3h, 2d), and hover actions **Pin**, **Snooze** and **Settle**. "Done" now means a finished reply you haven't seen; conversations you are finished with are **Settled**. Snoozing shows each wake time and offers **Custom…**. Right-click a row for its menu.
- **Inbox shortcuts**: ⌥↑ and ⌥↓ previous and next, ⌥⇧↓ next that needs you, ⌥⇧S settle and move on, ⌥⇧P pin, ⌥⇧U mark unread (Alt on Windows and Linux). See [Keyboard shortcuts](/docs/use/keyboard-shortcuts#in-the-inbox).
- **Rename conversations** with **Rename…** in a conversation's menu; the new name shows at once and on every device.
- The sidebar is resizable (drag its edge, or use the arrow keys on it; double-click resets).
- A turn the agent drops without replying shows **Failed** after 90 seconds, instead of Working for up to two hours.

## Chat

- **Tool steps**: an icon for the kind of tool, a spinner while it runs, red when it fails, and what it acted on. While the agent works, its latest steps show under the header. Opened, a step shows a command as `$ command`, simple inputs as name and value, JSON output indented, and **Copy**. See [Tool steps and reasoning](/docs/use/tool-steps-and-reasoning).
- **Failed replies say why in plain words**, with the provider's raw error under **Details**.
- A **No reply.** note under your message when the agent stopped without answering, with **Try again**.
- Conversations open at their latest message.
- Live labels shimmer, reasoning is quieter than the answer, long messages you send fold after 12 lines, and narrow no-break spaces some models write no longer squash words together.

## Brand

- The Face logo: favicons, app icons and the mark beside the name. The default name is **Pi Agent Interface**.

## Fixes

- On a shared browser, the next person to sign in inherited the previous person's theme, accent and avatar style.
- Leaving a conversation while its agent was working showed the agent as done.

## Upgrading from v0.1.0

- **A database is now required.** Set `DATABASE_URL` to an empty PostgreSQL database; the server creates its tables on start. See [PostgreSQL and migrations](/docs/operate/database).
- **Set `INITIAL_ADMIN_EMAIL`** so the instance gets an administrator: v0.1.0 had none.
- **Everyone signs in again once**: sessions now carry a session version, and v0.1.0's sessions end.
- **Assistants are kept.** Each person's assistant has the same key on the platform (`u:<person>`) and becomes their built-in provided agent, with its conversations.
- `AGENT_MODEL` is new and optional; Admin → Agents can choose the default model instead.
