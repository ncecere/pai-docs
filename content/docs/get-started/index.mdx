Pi Agent Interface is an open-source (MIT) chat app that an organisation runs for its own people, in front of a [Pi Durable platform](https://github.com/ncecere/pi-durable-platform). Everyone who signs in gets their own agents: an assistant to start with, the agents an administrator provides, agents they make themselves and, in Connect mode, their teams' agents. Agents keep working while you are elsewhere, so the app gives you an **inbox** across all your conversations: which are working, which have a new reply, which failed, and which you have snoozed, settled or put away.

People sign in to Pi Agent Interface with your single sign-on. To reach their agents, the app's server uses the agent platform in one of two ways. In **Connect** mode, the default, each person [connects their own platform account](/docs/use/connect-your-platform-account) once after signing in, their agents live in their personal workspace on the platform, and the server calls the platform with their own token. For a platform without Connect, **service** mode uses one team service account instead, and the server checks on every request that the agent being reached is the signed-in person's own.

## How it is built

Pi Agent Interface is one Node.js server that serves the web app and its API from one container image. It keeps its own records (the people who have signed in, their roles, settings, preferences and an audit log) in **PostgreSQL**, and migrates the database when it starts. The agents and their conversations live on the **Pi Durable platform**: in each person's personal workspace, reached with that person's own token (kept encrypted, and never sent to the browser), or, in service mode, in a team the app reaches with a service account key that never leaves the server. Sessions are encrypted cookies, so there is no session store to run.

```text
Morgan, Priya, Sam ──sign in──▶ Pi Agent Interface ──each person's own token──▶ Pi Durable platform
                    (and connect     │                       (Connect mode)       ├─ Priya's personal workspace
                     once)           ├─ PostgreSQL: people, roles,               ├─ Sam's personal workspace
                                     │  settings, encrypted tokens, audit log    ├─ Morgan's personal workspace
                                     └─ encrypted session cookie                 └─ their teams' agents
```

The web app comes from [Open Chat Interface](https://github.com/ncecere/open-chat-interface), so its layout, Settings and admin dashboard will look familiar to anyone who has used it. See [The agent platform](/docs/operate/platform) for what the app asks of the platform, in either mode.

## Project status

Pi Agent Interface is **pre-1.0**. The latest release is **v0.3.1** (2026-10-18), and these docs describe it: Connect, the app's own database, the admin dashboard, Settings, people's own agents and a published, signed container image. See [Releases](/docs/releases). In short:

- The app's HTTP API serves its own web app. It is not a public contract and may change in any release.
- Database migrations are forward-only. Going back past one means restoring a backup.
- The container image is published and signed: `ghcr.io/ncecere/pi-agent-interface:v0.3.1`. See [The container image](/docs/operate/container#getting-the-image).
- People [connect their own platform account](/docs/use/connect-your-platform-account) once, so their agents live in their personal workspace. A platform without Connect still works with a team service account.
