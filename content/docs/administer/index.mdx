Administrators run an instance of Pi Agent Interface from the **admin dashboard**: **Admin dashboard** in the menu under your name, or **Open admin dashboard** in the command palette. It is at `/admin`, for administrators only; the server checks every request too. **Back to chat**, at the foot of its page list, returns to your conversations.

| Group | Page | What it is for |
|---|---|---|
| | [**Overview**](#overview) | Who uses the instance and what has changed lately. |
| People | [**People**](/docs/administer/people-and-roles) | Everyone who has signed in: make administrator or member, suspend or restore. |
| Instance | [**Agents**](/docs/administer/agents) | The default model, people's own agents, allowed templates and the provided agents. |
| | [**Branding**](/docs/administer/branding) | The name, logo and default look. |
| | [**Features**](/docs/administer/features) | Optional parts of the app this instance can do without. |
| Records | [**Usage**](/docs/administer/usage) | Requests, tokens and estimated cost per person: the team's report in service mode (on by default), or each connected person's own in Connect mode ("Usage of connected people", off by default). |
| | [**Audit log**](/docs/administer/audit-log) | Every change to people, roles and settings. |

Every change in the dashboard takes effect at once and is recorded in the audit log.

## What administrators can't see

Administrators manage people and settings, not conversations. Nothing in Pi Agent Interface shows an administrator anyone else's agents or what was said to them. (Message search, if you turn it on, keeps a copy of conversation text for each person's own search; nobody but that person can search it in the app. See [Features](/docs/administer/features#search-message-text).) In service mode, the team's owners see the agents the app made on the platform (their status and when they were last used) but not their conversations. In Connect mode people's agents are in their own personal workspaces.
