---
title: Keyboard shortcuts
description: The keys that work everywhere in Pi Agent Interface, in the message box, and for moving through the inbox.
---

Pi Agent Interface can be used from the keyboard. Every control is reachable with Tab and shows a visible focus ring, and **Skip to main content** is the first tab stop on every page. On Windows and Linux, read `⌘` as `Ctrl`, `⌥` as `Alt` and `⇧` as `Shift`. The **Keyboard shortcuts** card in Settings lists them all, in your platform's own keys.

## Everywhere

| Keys | Does |
|---|---|
| `⌘ K` | Opens the command palette (below). |
| `⌘ ⇧ O` | Starts a new chat, with the cursor in the message box. |
| `⌘ B` | Shows or hides the sidebar. |
| `Escape` | Closes the open dialog, menu or panel. |

`⌘ ⇧ O` and `⌘ B` work anywhere in the chat, including while you type a message, but not while an input method is composing text.

## The command palette

`⌘ K`, or **Search commands and agents** when the sidebar is closed, opens a box that says **Type a command, an agent, or a question...**. As you type it offers:

- **Agents**: **New chat with *agent*** for each of your agents.
- **Chat**, **Settings** and the other commands: **New chat**, **Open settings**, **Open admin dashboard** (administrators), **Switch to light theme** or **Switch to dark theme**, and **Open sidebar** or **Close sidebar**.
- **Actions**: **Ask *agent*: "*what you typed*"**, which starts a conversation with your last-used agent with what you typed as its first message.

`↑` and `↓` move through the list, `Home` and `End` jump to its ends, and `Enter` chooses.

## In the message box

| Keys | Does | With **Enter adds a new line** on |
|---|---|---|
| `Enter` | Sends the message | Starts a new line |
| `⇧ Enter` | Starts a new line | Starts a new line |
| `⌘ Enter` | Sends the message | Sends the message |

Turn **Enter adds a new line** on in **Appearance settings** (top right) or [Settings → Customization](/docs/use/settings#customization). A held key sends once.

## In the inbox

| Keys | Does |
|---|---|
| `⌥ ↑` | Opens the previous conversation in Pinned, Working and Inbox. |
| `⌥ ↓` | Opens the next one. |
| `⌥ ⇧ ↓` | Opens the next conversation that needs you (**Done** or **Failed**). "Nothing else needs you." when there is none. |
| `⌥ ⇧ S` | Settles the open conversation and moves on to the next. Not while the agent is working. |
| `⌥ ⇧ P` | Pins or unpins the open conversation. |
| `⌥ ⇧ U` | Marks the open conversation unread. |

The inbox shortcuts use `⌥` (Alt) because browsers keep `⌘` with brackets and numbers for switching tabs. Each change says what it did, with **Undo**.

## Elsewhere

- **The agent picker**: type to search, `↑` `↓` to move, `Enter` to choose.
- **The sidebar's edge** (**Resize sidebar**): `←` and `→` make it narrower or wider (with `⇧`, in bigger steps), `Home` and `End` make it as narrow or as wide as it goes.
- **Search conversations...**: `Escape` clears the search.
