---

Pi Agent Interface is one Node.js server, in one container image, that serves the web app and its API. It needs:

| Needs | For | See |
|---|---|---|
| **A Pi Durable platform** with a team, an editor service account and its key, and a model published to the team | The agents and their conversations | [The agent platform](/docs/operate/platform) |
| **An OpenID Connect provider** with a confidential client | Sign-in | [Sign-in](/docs/operate/sign-in) |
| **PostgreSQL** | People, roles, settings, preferences and the audit log | [PostgreSQL and migrations](/docs/operate/database) |
| **A reverse proxy or ingress** that terminates TLS and doesn't buffer event streams | The public https address | [The container image](/docs/operate/container#behind-a-reverse-proxy) |

The server is configured with environment variables, checked when it starts: an incomplete or unsafe configuration stops it with every problem listed. See [Configuration](/docs/operate/configuration).

```text
browser ──https──▶ reverse proxy ──▶ Pi Agent Interface (:8080) ──https + service key──▶ Pi Durable platform
                                        │
                                        └──▶ PostgreSQL
```
